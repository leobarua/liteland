11Workspaces, outputs and file formats

The workspace folder

Each orthomosaic gets its own workspace folder, named after the image and placed beside it. The folder is created the first time you save the workspace or the points, or run an assessment.

data/ ├── Ortho_sample.tif ├── DSM_sample.tif └── Ortho_sample_workspace/ ├── session.json settings, file paths, classes, training samples ├── segments.tif segment ID of every pixel ├── segments.gpkg segment polygons ├── segment_features.csv the 19 or 23 features of every segment ├── classified_map.npy last classification, before the sieve ├── Ortho_sample_classified.tif exported map (Export Final Classified TIF) ├── Ortho_sample_classified.qml QGIS style for the exported map ├── accuracy_points.gpkg reference points and their labels └── accuracy_report.csv confusion matrix and accuracies

Reopening a workspace

  • With the orthomosaic already loaded: click Load Workspace; Lite Land reads that image's workspace folder.
  • From a fresh start: click Load Workspace on Tab 1 and pick the workspace folder. Lite Land reopens the recorded orthomosaic and DSM and resamples them to the saved resolution.
  • If files have moved, Lite Land asks you to locate them.

Reset and Return to Loading on Tab 2 clears the session in memory and returns to Tab 1. It does not delete anything on disk.

14Known limits

  • RGB only. There is no near-infrared band, so no NDVI. Visible-light indices, texture and height do that job.
  • One scene at a time. A model trained on one flight is not automatically valid for another; light and season change colours. Normalise radiometry outside Lite Land before reusing samples across flights.
  • GPU memory caps scene size. Resample large mosaics.
  • Segmentation is parameter-sensitive. Results depend on Num Segments, compactness and sigma; record the values you used (they are saved in session.json).
  • Photo-interpreted reference is not ground truth. Report it as reference data.

15Glossary

Adjacency graphThe list of which segments share a border. Used by the grow tool, merging and the neighbour features.
CIELABA colour space in which equal distances look like equal colour differences. SLIC clusters in it.
Confusion matrixA table of map class (rows) against reference class (columns) for a set of points. Also called an error matrix.
DSMDigital Surface Model: height of the top surface, including trees and roofs. Not the bare ground.
FeatureOne measured property of a segment, such as mean green or slope. Lite Land uses 19, or 23 with a DSM.
GLCMGrey-level co-occurrence matrix: a tally of how often grey levels sit next to each other. The source of the texture features.
GSDGround sample distance: the ground width of one pixel, e.g. 8 cm.
MMUMinimum mapping unit: the smallest patch the map keeps. Set by the sieve.
OBIAObject-based image analysis: classifying groups of pixels (objects) rather than single pixels.
OrthomosaicA geometrically corrected mosaic of drone photos, with map coordinates.
Overall accuracyShare of all reference points the map labels correctly.
Producer's accuracyFor one class: share of its reference points the map found. Measures omission.
Random ForestA classifier made of many decision trees, each trained on a random resample, that vote.
Reference dataLabels used to check a map. Photo-interpreted reference is distinct from field-verified ground truth.
ResampleChange the pixel size of an image, here by averaging to a coarser grid.
Segment / objectA connected group of similar pixels produced by segmentation. The unit Lite Land classifies.
SieveA filter that absorbs patches below a size into their surroundings.
SLICSimple Linear Iterative Clustering: the segmentation algorithm Lite Land uses.
Training sampleA segment you labelled to teach the classifier.
User's accuracyFor one class: share of the points the map puts in that class that really belong to it. Measures commission.
